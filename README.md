# Задание 7. Калькулятор

Калькулятор читает по одному выражению из терминала и выводит результат. Вычисления выполняются с типом `float`. Калькулятор разбирает выражения с помощью регулярного выражения и двух стеков, без `eval`.

## Установка и запуск

Нужен Python 3.10 или новее. Выполните команды из корня репозитория.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
python -m calculator
```

Для выхода нажмите `Ctrl+D` (в Windows — `Ctrl+Z`, затем `Enter`) или `Ctrl+C`.

## Выражения

Поддерживаются `+`, `-`, `*`, `/`, круглые скобки и унарные знаки `+` и `-`. Можно вводить десятичные числа (`0.5`, `.5`) и числа в экспоненциальной записи (`1.5e-2`).

### Порядок операций и степень

Сначала вычисляются выражения в скобках. Затем идут степень, унарные знаки, умножение и деление, сложение и вычитание. Умножение и деление одного уровня выполняются слева направо, как и сложение и вычитание.

`^` и `**` обозначают одну и ту же операцию. Степени вычисляются справа налево. Например, `2^3**2` означает `2^(3^2)` и даёт `512.0`. Запись `-2^2` даёт `-4.0`, а `(-2)^2` даёт `4.0`. Знак в начале показателя разрешён, поэтому `2^-2` даёт `0.25`.

Если степень конечного отрицательного числа с дробным показателем не определена для вещественных чисел, калькулятор выводит ошибку. Ноль в отрицательной степени и переполнение при возведении в степень дают бесконечность с учётом знака.

### Предыдущий результат

`_` подставляет последний успешно вычисленный результат текущего сеанса. До первого результата `_` вызывает ошибку. Если очередное выражение содержит ошибку, сохранённый результат остаётся доступен.

```text
> 2^3**2
512.0
> _ / 2
256.0
> 2 +
Error: expected a value before the end of the expression
> _ + 1
257.0
```

### Деление на ноль и специальные значения

Калькулятор принимает `inf`, `+inf`, `-inf` и `nan`. При делении ненулевого числа на `0` или `-0` результатом будет бесконечность. Если знаки числителя и знаменателя совпадают, результат положительный, иначе отрицательный. Деление нуля на ноль даёт `nan`.

| Выражение | Результат |
| --- | --- |
| `1 / 0` | `inf` |
| `1 / -0` | `-inf` |
| `-1 / -0` | `inf` |
| `0 / 0` | `nan` |
| `inf / inf` | `nan` |
| `inf - inf` | `nan` |
| `0 * inf` | `nan` |
| `1 / inf` | `0.0` |

`inf` и `nan` считаются результатами вычисления и тоже сохраняются в `_`.

## Тесты

После установки запустите `python -m pytest` из корня репозитория. Тесты проверяют порядок операций, обе записи степени, предыдущий результат, специальные значения и обработку ошибочного ввода.
