# Задание 7. Калькулятор

Интерактивный калькулятор для вычислений с вещественными числами. Выражения будут разбираться без `eval`. Символ `_` позволит подставить результат предыдущего вычисления.

## Установка и запуск

Нужен Python 3.10 или новее. Выполните команды из корня репозитория.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
python -m calculator
```

Сейчас команда запуска выводит сообщение о готовности каркаса. В каталоге `tests/` подготовлены файлы для проверки вычислений и работы в интерактивном режиме.
